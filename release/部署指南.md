# MCQQBridge 服务器部署指南

本模组实现 **Minecraft 26.2 服务器 ↔ QQ 官方机器人** 的双向消息互通。

## 一、需要准备的东西

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Minecraft 服务器 | **26.2** | 需使用 **Fabric 服务端**（不是原版/Vanilla） |
| Fabric Loader | **>= 0.19.3** | 服务器 mods 加载器 |
| Fabric API | 任意支持 26.2 的版本 | 本模组的前置依赖 |
| Java | **JDK 25**（或更高） | 服务器运行环境 |
| 本模组 | `mcqqbridge-1.0.0.jar` | 本目录中的 jar |

## 二、部署步骤

### 1. 搭建 Fabric 服务器
- 前往 https://fabricmc.net/use/server/ 下载 **Fabric Server Launcher**（选 MC 26.2 + Loader 0.19.x）
- 运行一次以生成服务器文件（`fabric-server-launch.jar` 放服务器目录，双击/命令行运行 `java -jar fabric-server-launch.jar`）
- 确认 `eula.txt` 中 `eula=true`（同意协议）

### 2. 放入模组文件
把以下两个文件放入服务器的 **`mods`** 文件夹：
- `mcqqbridge-1.0.0.jar`（本模组）
- `fabric-api-*.jar`（到 https://modrinth.com/mod/fabric-api 下载，选 26.2 版本）

### 3. 启动服务器
启动服务器后，模组会在 **`config/mcqqbridge.json`** 生成默认配置文件。
> 提示：本目录下的 `mcqqbridge.example.json` 是参考样例，可照着填写。

### 4. 填写 QQ 机器人凭证
编辑服务器的 `config/mcqqbridge.json`，核心字段：

```json
{
  "enabled": true,
  "app_id": "你的 QQ 机器人 AppID",
  "client_secret": "你的 QQ 机器人 AppSecret",
  "qq_to_mc": {
    "enabled": true,
    "groups": [],
    "accept_group_at": true,
    "accept_group_message": true,
    "accept_private_message": true,
    "format": "{sender}: {message}"
  },
  "mc_to_qq": {
    "enabled": true,
    "target_groups": ["目标群的 group_openid"],
    "forward_chat": true,
    "forward_game_message": false,
    "forward_command_message": false,
    "format": "[MC] {player}: {message}"
  },
  "mc_broadcast_prefix": "[QQ]",
  "qq_command_prefix": "/mc"
}
```

字段说明：
- **`app_id` / `client_secret`**：QQ 开放平台（https://q.qq.com）创建机器人后获得
- **`target_groups`**：MC → QQ 转发到的群 `group_openid`（在开放平台/沙箱环境里查看群 openid）
- **`qq_to_mc.groups`**：允许 QQ → MC 的群列表，留空 `[]` 表示不限制
- 各 `enabled` / `forward_*` 开关控制转发内容

### 5. 在 QQ 开放平台配置
- 在机器人「开发设置」中启用 **WebSocket 连接**
- 申请需要的**消息权限**：群聊消息 / 单聊消息
- 将机器人拉入你的目标 QQ 群

### 6. 重载配置
改完配置文件后，在游戏内执行：`/mcqq reload`（无需重启服务器）

## 三、功能一览

| 功能 | 说明 |
|------|------|
| MC → QQ | 玩家聊天、系统消息（进服/退服/死亡/成就，默认关）、/say /me 命令广播（默认关）自动转发到目标群 |
| QQ → MC | 群聊 / 单聊消息转发到游戏内（黄色系统消息显示） |
| QQ 指令 | 在 QQ 群发送 `/mc status`（互通状态）、`/mc online`（MC 在线玩家）、`/mc help` |
| MC 指令 | `/mcqq status`（互通状态）、`/mcqq reload`（重载配置）、`/mcqq help` |

## 四、常见问题

**Q：服务器启动报错「Missing mods / fabric-api」？**
A：确认 `mods` 文件夹里有 Fabric API 且版本匹配 26.2。

**Q：配置了但 QQ 收不到消息？**
A：检查 ① `app_id`/`client_secret` 是否正确；② 服务器是否已申请消息权限；③ `target_groups` 是否填了正确的群 openid；④ 机器人是否在群里且群开启了「允许机器人接收消息」。

**Q：QQ 官方 Bot 有频率限制吗？**
A：有。被动消息群聊约 5 分钟 5 次，模组已内置按 `msg_id + msg_seq` 去重。高频场景建议使用主动消息或企业自建应用。

**Q：需要公网 IP 吗？**
A：不需要。本模组使用 **WebSocket 长连接**主动连到 QQ 服务器，只要服务器能访问外网即可。
